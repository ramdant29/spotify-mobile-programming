## Installation

Clone Project

```bash
git clone https://github.com/ramdant29/spotify-mobile-programming
```

Masuk ke project directory

```bash
cd spotify-mobile-programming
```

Update Dependencies

```bash
flutter pub get
```

Jalankan Aplikasi
```bash
flutter run
```
